# SHOP-234: На stage карточка товара и добавление в корзину отдают 500

| | |
|---|---|
| Тип | Bug |
| Приоритет | **Critical** |
| Компоненты | catalog, cart |
| Автор | Мария Л. (QA) |
| Связано | SHOP-190 (кэширование товаров), [ADR-0004](../adr/0004-product-cache.md) |

## Описание

После выкладки SHOP-190 на stage (на stage Redis есть, на dev-стенде кэш раньше был выключен):

```
GET /api/v1/products/1001             → 500 {"code":"INTERNAL_ERROR"}
POST /api/v1/cart/items {1001, 1}     → 500
GET /api/v1/products                  → 200 (!)
```

Список товаров работает, а карточка нет.

## Критерии приёмки

- [ ] Карточка товара и добавление в корзину работают при включённом Redis.
- [ ] Решение соответствует ADR-0004.
- [ ] Есть интеграционный тест, который ходит в эндпоинт с реальным Redis (Testcontainers).
