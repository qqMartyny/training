# SHOP-254: Фронт не может отличить «не найдено» от падения сервера

| | |
|---|---|
| Тип | Bug |
| Приоритет | Minor |
| Компоненты | common |
| Автор | Денис Ф. (Frontend) |
| Связано | [openapi.yaml](../api/openapi.yaml), [ARCHITECTURE.md §10](../ARCHITECTURE.md) |

## Описание

`GET /api/v1/products/999999` → `500 INTERNAL_ERROR`. `GET /api/v1/orders/<случайный uuid>` → `500`.
По контракту должен быть `404 NOT_FOUND`. Сейчас мы показываем страницу «Сервис недоступен» вместо
«Товар не найден», а мониторинг заказчика считает это ошибками сервера и будит дежурного по ночам.
