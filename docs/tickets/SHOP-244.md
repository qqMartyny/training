# SHOP-244: Просмотр заказа (GET /orders/{id}) отдаёт 500, а автотесты зелёные

| | |
|---|---|
| Тип | Bug |
| Приоритет | **Critical** |
| Компоненты | order |
| Автор | Мария Л. (QA) |

## Описание

Сразу после успешного checkout:

```
GET /api/v1/orders/{orderId}           → 500
POST /api/v1/orders/{orderId}/cancel   → 500 (но заказ отменяется!)
GET /api/v1/orders                     → 200
```

В логе `LazyInitializationException ... (no session)`.

`OrderApiIT.returnsOrderWithItems` при этом зелёный. Я специально проверила, что он запускается.

## Комментарии

**Пётр С.:** Включите `spring.jpa.open-in-view: true`, и всё заработает, по умолчанию же он включён.

**Андрей К.:** Нет. Почему — в ARCHITECTURE.md, раздел 2. И разберитесь, почему тест зелёный.
Это важнее самого бага.

## Критерии приёмки

- [ ] Эндпоинты заказа работают при `open-in-view: false`.
- [ ] При загрузке заказа с позициями нет N+1 запросов (проверь по логу SQL).
- [ ] Интеграционный тест падает на старом коде. В PR объяснено, почему старый тест проходил.
