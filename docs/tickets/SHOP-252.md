# SHOP-252: Сервис доставки получает события заказа не по порядку

| | |
|---|---|
| Тип | Bug |
| Приоритет | Major |
| Компоненты | notification |
| Автор | Команда Delivery Service |
| Связано | [asyncapi.yaml](../api/asyncapi.yaml), [ADR-0003](../adr/0003-order-events.md) |

## Описание

Иногда для одного заказа мы получаем `PAID` раньше `NEW` или `DELIVERED` раньше `SHIPPED`. Наш
консьюмер (3 инстанса, по одному на партицию) обрабатывает их как пришли, статусы у нас ломаются.
В контракте написано, что порядок событий одного заказа гарантирован.

## Критерии приёмки

- [ ] Все события одного заказа попадают в одну партицию.
- [ ] Тест проверяет ключ сообщения и порядок событий одного заказа, читая их из Kafka.
- [ ] `OrderEventsIT` проверяет что-то осмысленное.
