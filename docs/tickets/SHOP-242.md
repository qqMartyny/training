# SHOP-242: Удаление товара из корзины возвращает 500, но товар удаляется

| | |
|---|---|
| Тип | Bug |
| Приоритет | Major |
| Компоненты | cart |
| Автор | Денис Ф. (Frontend) |
| Связано | [openapi.yaml](../api/openapi.yaml) `DELETE /api/v1/cart/items/{productId}` |

## Описание

`DELETE /api/v1/cart/items/1001` → 500. Если после этого обновить страницу, товара в корзине нет.
Фронт показывает пользователю «Что-то пошло не так», пользователь пробует ещё раз, опять 500.

По контракту ответ — `CartView` (как у остальных методов корзины). В логе бэкенда что-то про
`HttpMessageNotWritableException` и `nesting depth`.

## Критерии приёмки

- [ ] Ответ соответствует контракту OpenAPI.
- [ ] Ни один эндпоинт сервиса не отдаёт JPA-сущность напрямую. Проверь все контроллеры, не только корзину.
