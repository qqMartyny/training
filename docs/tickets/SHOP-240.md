# SHOP-240: Checkout падает при трёх товарах и промокоде; скидка в чеке больше цены товара

| | |
|---|---|
| Тип | Bug |
| Приоритет | Major |
| Компоненты | pricing |
| Автор | Мария Л. (QA), Елена В. (бухгалтерия заказчика) |
| Связано | [SPECIFICATION.md §3.2](../SPECIFICATION.md) |

## Описание

**Мария Л.:** В корзине три разных товара + `WELCOME1000` → корзина и checkout отдают 500.
С двумя товарами работает. С тремя товарами и `SALE15` то работает, то нет: зависит от товаров.

```
java.lang.ArithmeticException: Non-terminating decimal expansion; no exact representable decimal result.
```

**Елена В.:** В фискальных чеках скидка распределена по позициям неправильно. Пример с тестового стенда:
клавиатура 7990 ₽ и кабель 390 ₽, промокод на 1000 ₽. В чеке скидка на кабель 500 ₽, то есть кабель
стоит −110 ₽. Онлайн-касса такой чек не примет. Требования к распределению — в спецификации, раздел 3.2.

## Критерии приёмки

- [ ] Распределение скидки соответствует §3.2 (пропорционально, сумма сходится до копейки,
      остаток на последнюю позицию, скидка позиции ≤ её стоимости).
- [ ] Тест с суммами, которые не делятся нацело (пример из спецификации: 10 ₽ на 3 позиции).
- [ ] Существующий тест на распределение проверяет **значения**, а не только количество элементов.
