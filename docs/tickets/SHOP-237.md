# SHOP-237: Счёт на оплату криптовалютой выставляется на 0.00 BTC

| | |
|---|---|
| Тип | Bug |
| Приоритет | **Critical** |
| Компоненты | payment |
| Автор | Мария Л. (QA) |
| Связано | SHOP-215, [SPECIFICATION.md §4.3](../SPECIFICATION.md) |

## Описание

Оформила заказ на гарнитуру (5490 ₽) с оплатой криптой:

```json
"payment": {
  "method": "CRYPTO",
  "status": "PENDING",
  "cryptoAddress": "bc1q3f...",
  "cryptoAmount": 0.00,
  "cryptoCurrency": "BTC"
}
```

Монитор за 32 990 ₽ — тоже `0.00`. В итоговой сумме заказа нет сервисного сбора 1,5 %,
который обещан в спецификации.

## Комментарии

**Пётр С.:** Юнит-тест на конвертацию есть, и он зелёный.

## Критерии приёмки

- [ ] Сумма в BTC считается по спецификации (точность, направление округления).
- [ ] Сервисный сбор считается и входит в `total`.
- [ ] Юнит-тест проверяет **настоящий** `CryptoPaymentProcessor` на конкретных числах.
