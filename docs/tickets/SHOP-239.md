# SHOP-239: Заказ с отрицательной суммой

| | |
|---|---|
| Тип | Bug |
| Приоритет | **Critical** |
| Компоненты | pricing |
| Автор | Светлана Р. (поддержка) |
| Связано | [SPECIFICATION.md §2.4](../SPECIFICATION.md) |

## Описание

Покупатель положил в корзину кабель USB-C за 390 ₽, применил `WELCOME1000` и оформил заказ.
В заказе `total: -610.00`. Бухгалтерия в шоке, банк в шоке. Покупатель доволен.

## Критерии приёмки

- [ ] Итог заказа не бывает отрицательным ни при каком промокоде.
- [ ] Тест на граничные случаи: скидка больше суммы, равна сумме, сумма корзины 0.
