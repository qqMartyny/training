# SHOP-238: Промокод SALE15 даёт скидку 15 ₽ вместо 15 %

| | |
|---|---|
| Тип | Bug |
| Приоритет | Major |
| Компоненты | pricing |
| Автор | Ольга Н. (PM заказчика) |
| Связано | [SPECIFICATION.md §2](../SPECIFICATION.md) |

## Описание

Маркетинг запустил рассылку с промокодом **SALE15** («минус 15 % на всё»). Покупатели жалуются:
корзина на 11 640 ₽ после применения промокода стоит 11 625 ₽.

`MINUS500` и `WELCOME1000` работают правильно.

## Комментарии

**Мария Л. (QA):** Юнит-тест на процентный промокод есть, зелёный. Странно.

**Ольга Н.:** И напоминаю: в Q4 маркетинг хочет промокоды «N+1 в подарок» и «бесплатная доставка».
Хочется, чтобы это не превратилось в ещё один такой баг.

## Критерии приёмки

- [ ] Скидка по `SALE15` считается в процентах.
- [ ] Типы скидок — не «магические строки». Опечатка в типе ловится компилятором или падает на старте,
      а не превращается молча в другой тип скидки.
- [ ] Новый тип промокода добавляется новым классом без правки расчёта существующих типов.
- [ ] Тестовые данные в юнит-тестах соответствуют тому, что реально лежит в БД.
