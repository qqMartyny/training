# SHOP-246: [Pentest] Доступ к чужим заказам

| | |
|---|---|
| Тип | Security |
| Приоритет | **Critical** |
| Компоненты | order |
| Автор | Отчёт внешнего пентеста, находка #3 |
| Связано | [ARCHITECTURE.md §9](../ARCHITECTURE.md), [SPECIFICATION.md §8](../SPECIFICATION.md) |

## Описание (из отчёта)

> **Находка #3 (High): Insecure Direct Object Reference в API заказов.**
> Аутентифицированный пользователь A может получить данные заказа пользователя B, а также отменить его,
> если знает идентификатор заказа. Идентификатор заказа передаётся в письмах, в URL страницы
> отслеживания и в реферальных ссылках службы доставки.
>
> PoC: `GET /api/v1/orders/{orderId_B}` с токеном пользователя A → `200 OK`, тело содержит состав
> заказа пользователя B.

## Критерии приёмки

- [ ] Покупатель видит и отменяет только свои заказы.
- [ ] Для чужого заказа ответ неотличим от ответа для несуществующего.
- [ ] Проверка доступа сделана на уровне запроса к БД, а не фильтрацией после загрузки.
- [ ] Есть интеграционный тест на этот сценарий.
