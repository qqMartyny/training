# SHOP-233: В отчёте CI нет ни одного интеграционного теста

| | |
|---|---|
| Тип | Tech debt |
| Приоритет | Major |
| Компоненты | build, tests |
| Автор | Мария Л. (QA Lead) |

## Описание

В `src/test` лежат интеграционные тесты `*IT` (`CheckoutFlowIT`, `OrderApiIT`, `OrderEventsIT`,
`ProductCacheIT`). В отчёте пайплайна (`./mvnw verify`) их нет: сборка проходит за ~20 секунд,
хотя один только старт Testcontainers занимает дольше. В IDEA они запускаются по кнопке.

Подозреваю, что последние полгода интеграционные тесты в CI вообще не гонялись.

## Критерии приёмки

- [ ] `./mvnw verify` запускает интеграционные тесты, и это видно в логе сборки.
- [ ] `./mvnw test` по-прежнему запускает только быстрые тесты.
- [ ] Если после включения интеграционные тесты падают, это не повод их отключать.
      Это новые баги: заведи их или найди среди существующих тикетов.
