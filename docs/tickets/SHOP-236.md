## Описание

Тестируем на stage новые способы оплаты. После оформления заказа через СБП приложение показывает QR-код
(он правильный, банк его распознаёт), а в личном кабинете заказ уже в статусе «Оплата не прошла».
Корзина при этом не очищается. С криптой то же самое.

Картой всё работает.

## Шаги воспроизведения

1. Добавить в корзину любой товар.
2. `POST /api/v1/checkout {"paymentMethod": "SBP"}`

## Ожидаемый результат

`201`, `status = AWAITING_PAYMENT`, в ответе есть `payment.qrPayload`. Корзина очищена.
После `callback SUCCEEDED` заказ получает статус `PAID`.

## Фактический результат

`201`, `status = PAYMENT_FAILED`.
