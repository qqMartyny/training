# SHOP-255: [PCI DSS] Платёжные данные в логах

| | |
|---|---|
| Тип | Security |
| Приоритет | **Critical** |
| Компоненты | payment, config |
| Автор | Аудит ИБ заказчика |
| Связано | [ARCHITECTURE.md §9](../ARCHITECTURE.md), [SPECIFICATION.md §9.3](../SPECIFICATION.md) |

## Описание (из отчёта аудита)

> 1. В логах сервиса на stage (Elasticsearch, индекс `order-service-*`) обнаружены значения
>    `paymentToken`. Токен одноразовый, но до использования даёт право списать деньги.
> 2. В логах есть SQL-запросы с текстом каждого запроса к БД. Это объём логов и риск утечки данных
>    при включённом логировании параметров.

## Критерии приёмки

- [ ] Платёжные токены не попадают в логи ни при каком уровне логирования. Подумай, как защититься
      от того, что кто-то в будущем снова залогирует объект целиком.
- [ ] Логирование SQL выключено по умолчанию и включается только локально (профиль или уровень логгера).
