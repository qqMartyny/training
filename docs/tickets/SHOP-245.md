# SHOP-245: В заказе меньше позиций, чем было в корзине

| | |
|---|---|
| Тип | Bug |
| Приоритет | **Critical** |
| Компоненты | order |
| Автор | Светлана Р. (поддержка) |

## Описание

Покупатель заказал клавиатуру, мышь и кабель. Списали правильную сумму за все три товара,
а в заказе (и, соответственно, у склада и службы доставки) только одна позиция — клавиатура.
Покупатель получил только клавиатуру.

Таких обращений уже пять, во всех заказах больше одного товара.

## Критерии приёмки

- [ ] В заказе сохраняются все позиции корзины.
- [ ] Тест проверяет количество и состав позиций заказа **после сохранения в БД и повторного чтения**.
- [ ] В PR объяснено, какое правило работы с JPA-сущностями нарушено и как его соблюдать
      (подсказка: что такое `id` у сущности до `persist`?).
