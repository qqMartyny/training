# Changelog

## [1.3.0] — не выпущен

### Добавлено
- Оплата через СБП: динамический QR-код, подтверждение callback-ом (SHOP-212, Василий П.).
- Оплата криптовалютой (BTC): счёт на уникальный адрес, сервисный сбор 1,5 % (SHOP-215, Пётр С.).
- Расчёт итоговой цены для checkout вынесен в `PricingService` (SHOP-205).

### Известные проблемы
- См. бэклог спринта 14: `docs/tickets/README.md`.

## [1.2.0] — 2026-07-28

### Добавлено
- События о смене статуса заказа в Kafka для Notification и Delivery Service (SHOP-201).
- Кэширование карточек товаров в Redis (SHOP-190).
- Распределение скидки по позициям для фискального чека (SHOP-188).

## [1.1.0] — 2026-05-12

### Добавлено
- Промокоды: процентные и фиксированные, минимальная сумма заказа, срок действия (SHOP-150).
- Отмена заказа покупателем (SHOP-162).
- Внутренний эндпоинт смены статуса для Delivery Service (SHOP-170).

## [1.0.0] — 2026-03-30
